# Skills

38 skills across 10 lifecycle groups. Each is a folder with a `SKILL.md` that follows the
Role → Context → Workflow (Step 0 TodoWrite) contract. This table is generated from the real skill
frontmatter at build time.

## Expanded accessibility workflows

The seven accessibility skills retain scan, review, fix, independent verification,
test generation, development and reporting. One review skill contains the complete interactive,
contrast, color-only meaning, links, display modes and viewport procedures, selected through
`--mode interactive|contrast|color|links|modes|viewports|all`. One shared guidance document
contains all 55 WCAG 2.2 A/AA criteria, WCAG 2.1 boundaries, ten inspection and repair families,
twenty baseline/candidate scenarios and optional private policy templates.

Content, tables, forms/error recovery, authentication/repeated entry, status/progress, complex
widgets, keyboard/focus, visual modes/reflow, pointer/drag and media/timing retain explicit
applicability and untested coverage. DOM evidence does not establish speech behavior.
Portable prerequisite and release-inventory workflows are in the repository group.
FastPass and Lighthouse are not included in this synchronization.
