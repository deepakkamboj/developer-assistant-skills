# Skills

44 skills across 10 lifecycle groups. Each is a folder with a `SKILL.md` that follows the
Role → Context → Workflow (Step 0 TodoWrite) contract. This table is generated from the real skill

## Expanded accessibility workflows

The 13 accessibility skills retain scan, combined review, fix, independent verification,
test generation, development and reporting, with six focused reviews for interactive behavior,
contrast, color-only meaning, links, display modes and viewports. The combined review modes
remain supported. Shared guidance covers all 55 WCAG 2.2 A/AA criteria, WCAG 2.1 boundaries,
ten inspection and repair families, and twenty baseline/candidate scenarios.

Content, tables, forms/error recovery, authentication/repeated entry, status/progress, complex
widgets, keyboard/focus, visual modes/reflow, pointer/drag and media/timing retain explicit
applicability and untested coverage. DOM evidence does not establish speech behavior.
Portable prerequisite and release-inventory workflows are in the repository group.
FastPass and Lighthouse are not included in this synchronization.
