# Agents

Independent review critics, orchestrating leads and read-only evidence roles. This roster is generated
from the real agent frontmatter at build time.

<AgentsTable />

The `a11y` agent combines audit orchestration with read-only evidence review.
Review mode does not authorize repairs; independent fix verification and the separate diff
critic remain distinct responsibilities.

Work coordination, meeting preparation, evidence, metrics, adoption, contribution, impact and
dashboard roles use English IDs and approved provider-neutral inputs. Existing roles are reused
where responsibilities overlap. Enterprise provider intake belongs to a separate adapter, not
to a duplicated generic agent definition.
