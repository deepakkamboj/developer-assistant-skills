# Claude Code — Project Instructions

This repository uses a vendor-neutral `.developer/` agent system as the single source of truth.

**Read `.developer/AGENTS.md` first.** Skills are discovered from `.developer/skills/**/SKILL.md`.

- Open-source: no Microsoft-internal content.
- Single `config.json` via `DEVELOPER_CONFIG` (fallback `~/.developer/config.json`), plus
  `content.md` / `memory.md` / `notes.md`.
- Autonomous CI workflows are disabled by default — see `.github/workflows/README.md`.
- Skills are invocable as `/dev:<skill>` via `.claude/commands/dev/` (generated by
  `node .developer/scripts/gen-commands.js`). See `usage.md`.
